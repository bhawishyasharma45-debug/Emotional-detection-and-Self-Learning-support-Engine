# Emotion Detection & Learning Support Engine

An AI-powered system designed to analyze student emotion states from text inputs using a hybrid BiLSTM and BERT ensemble architecture, providing empathetic feedback loops via Gemini 1.5 Flash.

## Setup Instructions
1. Activate environment: `.venv\Scripts\Activate.ps1`
2. Install dependencies: `pip install -r requirements.txt`
3. Run dashboard: `streamlit run app.py`
